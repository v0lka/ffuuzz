# MITM Proxy

## Responsibility

Intercepts HTTP and HTTPS traffic via CONNECT tunneling with on-the-fly TLS certificate generation. Records all exchanges through the `Recorder` interface. Listens on configurable address (default `:8080`).

## Key Types

```go
type Config struct {
    ListenAddr    string
    CertStore     *store.CertStore
    Recorder      recorder.Recorder
    MaxBodyBytes  int
    TLSSkipVerify bool
    Logger        zerolog.Logger
}

type Proxy struct {
    cfg       Config
    transport *http.Transport
    server    *http.Server
    logger    zerolog.Logger
}
```

## Public API

### `New(cfg Config) *Proxy`
Creates a MITM proxy with an HTTP transport configured for idle connection pooling and optional TLS skip-verify.

### `ListenAndServe() (*http.Server, error)`
Starts the proxy server on `cfg.ListenAddr`. Returns the `*http.Server` so the caller can call `Shutdown`.

### `Shutdown(ctx context.Context) error`
Gracefully shuts down the proxy. Safe to call even if the server was never started.

### `ServeHTTP(w http.ResponseWriter, r *http.Request)`
Main handler. Dispatches based on request method:
- `CONNECT` → `handleCONNECT()` (HTTPS interception)
- Other → `handleHTTP()` (plain HTTP forwarding)

## Internal Flow

### HTTP Handling (`handleHTTP`)

```
1. Read request (method, URL, headers, body)
   │  ─ Uses LimitedBuffer for body (truncated at MaxBodyBytes)
   │
2. Forward request to origin server via transport.RoundTrip()
   │  ─ Removes hop-by-hop headers (httputil.RemoveHopByHop)
   │  ─ Uses TeeReadCloser to capture response body while forwarding
   │
3. Record TxRecord{request + response}
   │
4. Write response back to client
```

### HTTPS Handling (`handleCONNECT`)

```
1. Client sends CONNECT target.com:443
   │
2. Proxy dials TCP to target.com:443 (via proxy.DialContext or direct)
   │
3. Proxy responds 200 Connection Established to client
   │
4. Hijack client connection → raw net.Conn
   │
5. TLS MITM:
   │  a. certStore.GetCertFor(target.com) → dynamically signed leaf cert
   │  b. tls.Server(hijackedConn, tls.Config{Certificates: [leaf]})
   │     → TLS handshake with client using proxy's cert
   │  c. tls.Client(targetConn, tls.Config{ServerName: target.com})
   │     → TLS handshake with origin (optionally skip-verify)
   │
6. Two goroutines tunnel data:
   │  client → read plaintext → parse HTTP → forward → record → origin
   │  origin → read response → record → write plaintext → client
   │     (each read uses LimitedBuffer, each write uses TeeReadCloser)
   │
7. Record each exchange via cfg.Recorder.Record()
```

### Recording Details

- **Request body**: read into `LimitedBuffer`. If it exceeds `MaxBodyBytes`, the body is recorded as truncated and the full body is still forwarded.
- **Response body**: read via `TeeReadCloser` which streams bytes to a `LimitedBuffer` while writing to the client.
- **Hop-by-hop headers** are stripped before recording (but after forwarding to origin). Headers like `Transfer-Encoding`, `Connection`, `Proxy-Authorization` are not persisted.
- **Request ID**: generated by `httputil.NewRequestID()` (format: `YYYYMMDD-UUIDv4`).
- **Timing**: `started_at` is set before the request is forwarded. `duration_ms` is computed after the full response is received.

## Invariants

- The proxy implements `http.Handler` (`ServeHTTP`), so it can be used with any `http.Server`.
- CONNECT requests are hijacked at the TCP level. The proxy acts as a TLS-terminating reverse proxy for HTTPS traffic.
- Each hostname gets exactly one leaf certificate (enforced by `CertStore`'s LRU cache + `singleflight`). Concurrent CONNECT requests to the same host share the same cert.
- Body truncation is applied at recording time, not at forwarding time. The client always receives the full response body.
- Recording happens synchronously in the same goroutine as the request handling. A slow database cannot be hidden by buffering.
- The proxy's `http.Transport` uses connection pooling (100 max idle, 10 per host, 90s idle timeout). Connections to the same origin are reused.

## Edge Cases

- **CONNECT to unreachable host**: Proxy returns 502 Bad Gateway. Sets `ConnectErrors` metric.
- **TLS handshake failure with origin**: Proxy returns 502. Sets `CertErrors` metric.
- **Client disconnects mid-stream**: Proxy cancels the origin request (via `Request.Context()`). Partial recording is discarded.
- **Response body exceeds MaxBodyBytes**: Client receives the full body. The `TxRecord` has `RespTrunc = true`.
- **Request body exceeds MaxBodyBytes**: Client's full body is forwarded. The `TxRecord` has `ReqTrunc = true`.
